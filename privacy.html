Privacy policy

Last updated 20 October 2026

Calendar Agent is a personal tool used only by the person who built it. This page explains what it does with Google data.

What it accesses

With its owner's permission (Google's "calendar.events" access), Calendar Agent reads and changes events in its owner's Google Calendar: titles, dates, times, locations and reminders. It doesn't access any other Google data.

How the data is used

Only to do what its owner asks: show events, find free time, create, move or cancel events the owner has approved, and write the owner's morning summary.

Where it's processed

On its owner's own computer. The AI model that reads requests runs locally on that computer, so calendar data isn't sent to any AI service.

Who it's shared with

When the owner uses the Telegram bot, event details appear in messages sent to the owner's own private Telegram chat, through Telegram's servers. Nothing is shared with anyone else. The data isn't sold, used for advertising, or tracked with analytics.

What's stored

The Google login key, settings and a short activity log are kept only on the owner's computer. Conversations are held in memory and forgotten when the program stops.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Google's requirements

Calendar Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

Any changes to this policy will be published on this page.
